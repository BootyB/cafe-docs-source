== Introduction
---

This page is a collection of resources for players interested in learning more about Delubrum Reginae Savage (DRS), including guides, videos, and other helpful materials. Whether you're a seasoned veteran or new to the raid, these resources can help you prepare for your next run and improve your performance.

TIP: If you're looking for resources on the normal mode of Delubrum Reginae, check out the xref:resources-hub/delubrum-resources.adoc[Delubrum Reginae Resources] page for guides and helpful materials!

=== DRS Requirements

**Before the run, prepare:**

* Check raid leader's required lost actions list
* Farm or buy fragments if needed.

**Common DRS Lost Actions:**

* **Tanks**: Lost Rampage, Lost Focus
* **Healers**: Lost Seraph Strike, Lost Excellence
* **DPS**: Lost Font of Magic/Power, Lost Slash/Shot
