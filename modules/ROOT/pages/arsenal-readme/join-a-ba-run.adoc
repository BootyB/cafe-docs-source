== How to Join a BA Run On CAFE

• **Check the Schedule**: Look in `#⁠⁠⁠arsenal-schedule` for scheduled runs, the run type, and the raid lead. Be sure to read the run notes.
• **Wait for Password**: The password for Normal, Non-Standard, and Reclear runs will be pinged (@Arsenal Raider or @Ozma Cleared) in ⁠`#⁠arsenal-schedule` 30 minutes before the scheduled start time.
• **Join a Party**: Use the password to join an elemental party in the Private Tab of the Party Finder (PF) in-game. (See example image below.)
• **Support Group Password**: This may be different. DM the person mentioned in the ping for details. If DMs don't work, check `#⁠arsenal-chat` for updates on the Support Group.

== TL;DR
Check `#⁠⁠arsenal-schedule`, wait for the password ping 30 minutes before start time, and use it to join an elemental party in the Private Tab of the in-game Party Finder.

== Important Notes,
• Be **OUTSIDE Eureka** and **IN Kugane** to join a PF group and instance in.
• **First Clears (+1)**: While you are trying to get your first clear, you can contact the raid lead ahead of time (at least 2 hours before the run) to request a +1. You'll get the password early to join before public password drop and time permitting get some additional direction from the lead. Use responsibly (e.g., don't request for runs after your first clear. We'll know). Please see the next paragraph for some caveats.
• **Need Info?** Use /plusone in any channel for details about the next run or contacting the raid lead. Please note that this command will only return "Normal" runs. Nothing is stopping you from requesting or joining any other run type, but it's up to each raid lead's discretion if they'll make accommodations.

Remember: Always follow the raid lead's instructions and check run-specific notes!
