== Scheduling/Timestamps

• **Run Times**

All runs scheduled use Discord timestamps, which automatically adjust to your device's local time.

• **Example Timestamp**

Tuesday, June 24, 1969 6:20 PM

This timestamp will always show in your device's local time zone.

• **Avoid Assumptions**

Don't assume others are in your time zone. Saying "I'd like to join the run at 8pm!" can be confusing. Try to refer to the run ID or how many hours are left until the run.

== Run Types

• **Normal Run**:

A typical CAFE run with the intent to clear. While some tactics may differ between raid leads, this is generally a new player friendly run.

• **Reclear (RC**):

This type of run is usually aimed at going through BA quickly and without many explanations. Thus, it is usually for people who have already cleared BA.

• **Non-Standard**:

A not so typical CAFE run with a theme or condition that makes it not normal. Be sure to check the run notes and make sure your expectations match, as clearing is not a guarantee.
