Complete step-by-step guide for joining Forked Tower (FT), Delubrum Reginae Savage (DRS), and Baldesion Arsenal (BA) runs through CAFE's Proto-Ozma scheduling system.

== Overview

Proto-Ozma manages scheduled raid runs with different signup methods depending on the content type:

* **Forked Tower (FT)** - Role-based internal/external signups with reserves
* **Delubrum Reginae Savage (DRS)** - Role-based internal/external signups similar to FT
* **Baldesion Arsenal (BA)** - FFA passcode drop with Party leader signup system


This guide walks you through finding and joining runs for each type.

**Tips for Success:**

* ✅ **Sign up early** - Popular runs fill quickly
* ✅ **Be flexible** - Select multiple roles to increase chances
* ✅ **Set reminders** - Don't forget about runs 2-3 days out
* ✅ **Communicate** - Contact raid leader if you have questions
* ✅ **Withdraw early** - If you can't make it, withdraw ASAP
* ✅ **Stay updated** - Check the raid lead's thread regularly as run time approaches

== Finding Scheduled Runs

The first *important* step for joining in any content is to go to #channels and click the selection box next to the categories you are interested in, so that you will see the associated channels here in Discord.

=== Check Schedule Channels

CAFE Hosted Runs are posted in dedicated schedule channels:

* `#forked-schedule` - Forked Tower runs
* `#drs-schedule` - Delubrum Reginae Savage runs
* `#arsenal-schedule` - Baldesion Arsenal runs

External Runs are posted in the following channels:

* `#na-forked-schedule` - External Forked Tower runs
* `#na-drs-schedule` - External DRS runs
* `#na-arsenal-schedule` - External BA runs

TIP: External Runs are not hosted on CAFE and we will not be able to assist with signups or troubleshooting. Please contact the raid leader and join the other Discord server for help.

===  Scheduled Runs Channel Format

Each channel has runs that are seperated by type first and date second.

**Key Information:**

* **Date/Time** - When the run starts (time is automatically converted to your timezone according to your system)
* **Raid Leader** - Who's organizing the run 
* **Space Availability** - FT exclusive, this shows how many spots are left on the run.
* **Party Leads** - BA exclusive, this shows how many party leaders have signed up for the run.
* **Thread/Signup Link** - Click here to go to the signup thread (FT/DRS)

TIP: Set a reminder! At the bottom of the channel click the "⏰ Set Reminder" button to get a DM reminder 90 minutes before the run starts with all the important info and signup status.

== Joining Forked Tower (FT) Runs

Forked Tower Raid leads in CAFE use **role-based internal signups** with either the CAFE exclusive Roster Manager or with External Sign-up systems. The signup method is determined by the raid lead and will be specified in the run announcement. Please read the announcement carefully to understand which method is being used for the run you want to join.


TIP: Please note there will be two versions of Forked Tower Runs in the future and both will be listed in the same area. Stay Tuned!

=== Reading the Schedule

All CAFE hosted Forked Tower runs are found in the `#forked-schedule` channel. Look for the run you want to join and click the signup thread link.

*How to read the schedule:*

* ** Date/Time** - When the run starts (automatically converted to your timezone)
* **Raid Leader** - Who's organizing the run
* **Space Availability** - Shows how many spots are left on the run

** *🟢 Green Light* - Signups Open
** *🟡 Yellow Light* - Signups are approaching full
** *🔴 Red Light* - Run is full, join the reserve queue!
** *🚫 Stop Sign* - Run is full, no reserves requested.

* **Discussion Thread** - Click here to go to the discussion thread for the run, where you can ask questions and coordinate with the other participants.
* ** Run ID# Sign-Ups** - Click this to go to the sign-ups thread for the run, where you can sign up and select your roles.

TIP: You can also hover over the #forked-chat to see the most active run channels to join!

=== Managing your Signups

FT Raid Leads that use the CAFE Roster Manager have an interactive signup system that allows you to select your roles and see the current signup status in real time. The signup thread will have a status embed that shows how many spots are available, which roles are needed, and if signups are open or closed.

*Example:*

[source]
----
📊 Forked Tower Signups
Run Time: May 5, 2026 @ 8:00 PM EDT

Signups: 35 / 48
Reserves: 3

Available Slots by Role:
├─ Tank: 2 / 6
├─ Healer: 1 / 12
├─ Healer(Shield): Open
├─ DPS(Melee): 8 / 12
├─ DPS(Phys Ranged): 5 / 12  
├─ DPS(Caster): 4 / 12
└─ DPS(Flex): 7 / 12

Status: ✅ Signups Open
----

**What This Tells You:**

* How many spots are available
* Which roles are needed most
* If signups are open or closed
* Reserve queue status

*How to Sign Up:*

1. Use the dropdown in the thread to select your your prefurred class. You can choose more than one role to increase your chances of getting in.
2. Once you submit your role selection, the bot will request your phantom job preferences to help the raid lead with party distribution. This step is optional but highly recommended.
3. On this page you can also request Prog Point from the `Request Prog Point` button, which will add a point to your total in the Prog Point Poll. This is a great way to show support for the run and help it get more votes in the poll, which can influence future raid scheduling and community focus.
4. After signing up, you can check your status in the thread or use the `My Signups` button. This will show all of your current signups, your role selections, and your party assignment once it's distributed. If the run is full, you'll be added to the reserve queue and will be automatically promoted if spots open up.

TIP: You can also use the command `/forked-preferences` to set your prefurred Phantom Job, Party, Default Timezone, Sit Out status and Party Homies. _Note: Party Homies will not work unless you have eachother on both of your accounts or it will not work_

Click the **Choose your role(s)** dropdown in the thread.

== Joining Baldesion Arsenal (BA) Runs

BA Raid Leaders in CAFE use **password drop** and a **party leader signups** for all BA runs.

Please note _Party Leader Signups_ are optional for BA runs. You can still join the run through the passcode drop method without signing up as a party leader, but signing up helps the raid lead with organization and planning. Keep in mind that you will be required to be responsible for your party of 8 players, so make sure you are comfortable with the role before signing up.

TIP: If you are looking for unlock requirements for BA, check out the xref:resources-hub/arsenal-resources.adoc[Baldesion Arsenal Resources] page for guides and helpful resources!

=== Reading the Schedule

_Find a run that works for you using the `#arsenal-schedule` channel for CAFE hosted runs or `#na-arsenal-schedule` for external runs._

*Key Information:*

* **Sprout New Player Friendly Runs** - These runs are specifically designed to be welcoming and educational for new players. If you're new to BA, look for these runs and join the voice calls for extra guidance and support. Feel free to ask questions in voice or text, the raid leads and community are here to help you learn! Vet's are more than welcome to join these runs as well, and your experience will be a great help to the new players.

* ** Star plusone button** - Indicates that the raid lead is using the plus-one system for first clears. This allows players to sign up before password drop to guarantee a spot into the upcoming run. To use plus-one, simply run the `/plusone` command and select the run you want to join. The raid lead will then approve your request and add you to the run. Please note that plus-one is for first clears only, so if the run has already cleared once, this option will not be available.

* Click the `⏰ Run Reminder` button to get a DM reminder 90 minutes before the run starts
* Click the `🔔 Follow Raid Leads` button to get notifications when your preferred Raid Lead schedules a run.
* Click the `ℹ️ Insructions` button for a quick refresher on how to join BA runs
* Click the `🔕 Toggle Pings` button to toggle your Forked Raider pings on and off

TIP: Please note you will not be able to use the `Scheduling` button unless you have have the BA Caller role. If you are interested in becoming a BA Caller, please reach out to a raid leader or staff member for more information.

=== How to Join a BA Run

**30 Minutes Before the Run:**

* The passcode will be posted in `#arsenal-passwords`
* All parties are free-for-all unless the raid lead specifies otherwise
* You will find the parties listed in the Private Tab of Party Finder in-game (Earth, Wind, Water, Fire, Lightning, Ice, and Support)
* Be sure to be Online and in Kugane before the passcode drops to ensure you can join quickly
* Feel free to join the BA West voice channel anytime after the passcode drops to coordinate with the party and listen to callouts. Being in voice call is never required but can enhance the experience and help with coordination.

TIP: If you used the `/plus-one` system, you will receive a DM with the passcode and party assignment 30 minutes before the run starts, so make sure your DMs are open!

=== Being A Party Leader

*If you want to lead a party:*

1. Go to `#arsenal-schedule` and click `party leads` to be taken to the #arsenal-party-leads announcement channel
2. Use the dropdown to select a party (Earth, Wind, Water, Fire, Lightning, or Ice)
3. Make sure you have DM's enabled for this server, as the bot will send you important information about your party and the run.

TIP: You can also use this same method to sign up for Perception or Spirit Dart roles as well!

*Party Leader Responsibilities:*

* **55 Minutes Before:** Party leaders receive the passcode to set up Party Finder
* **30 Minutes Before:** Passcode is posted publicly in `#arsenal-passwords`
* **During the Run:** Party Leads are responsible for coordinating their party with ready checks, marker placement, and communicating with the Raid Lead as needed. If you are unable to fulfill these responsibilities, please do not sign up as a party leader and instead join the run through the passcode drop method.

**Tips for Success:**

* Review `/ba_toolbox` mechanics before first run
* Bring appropriate logos actions for your role
* Listen to party leader - they're responsible for 8 people
* Support party is great for learning - don't be afraid to join it if you're new!


== Setting Up Reminders

Never miss a run with personal reminders!

=== Set a Reminder

**Method 1: Context Menu**

1. Right-click the run announcement
2. Apps → "Set/Remove Reminder"
3. Confirm in the interaction

**Method 2: Reminder Manager**

1. Look for "⏰ Reminder Manager" button (usually in FT/DRS threads)
2. Click to view all your reminders
3. Add new reminders via dropdown

=== How Reminders Work

* Bot DMs you **90 minutes before** the run starts
* Includes run details and current status
* Shows available spots and signup info
* Works for BA, FT, and DRS runs

**Example Reminder:**

[source]
----
⏰ Run Reminder - 90 Minutes Warning

Forked Tower Run
Starts: May 5, 2026 8:00 PM EDT (in 90 minutes)
Raid Leader: @RaidLeaderName

Your Status: Active - Party B (Right Side)
Role: DPS(Melee)

Current Signups: 47/48 (1 spot available)

Thread: [Click here to view]
----

=== Remove a Reminder

Same as setting one:

1. Right-click announcement → Apps → "Set/Remove Reminder"
2. Or use Reminder Manager to bulk remove



== Frequently Asked Questions

**Q: Can I sign up for multiple runs at the same time?**

A: Yes! Use `/my-signups` to track all your commitments. Just make sure times don't overlap.

**Q: What if I'm on reserve and the run fills up?**

A: Stay on reserve! People drop out frequently. Check the thread and the raid lead may open up more spots.

**Q: Can I change my role selection after signing up?**

A: Yes, just click the dropdown again in the thread or use `/my-signups` to update your roles.

**Q: How do party friends work?**

A: Set them with `/forked-preferences`. System tries to place you together, but can't guarantee it. Mutual preferences have higher priority. Raid leads can see this info when using the roster manager.

**Q: What if I sign up but can't make it?**

A: Withdraw ASAP using `/my-signups` or the thread's "Remove Signup" button. Helps reserves get promoted.

**Q: Can I be blacklisted from signups?**

A: Yes, repeated no-shows or disruptive behavior can result in signup restrictions. Contact staff if you believe this is an error.

**Q: How do I know if I got into a run?**

A: Check the signup status embed in the thread, or use `/my-signups`. You'll see "Active" or "Reserve #X". In the case of BA, you'll know you got in when you join a party in Party Finder after the passcode drops. Lightning hands may be required!

**Q: When are rosters distributed?**

A: Raid leads usually post rosters 1-6 hours before run time. The final roster is distributed with the passcode ping.

**Q: Can I request a specific party**

A: Absolutely! Use /forkred-preferenced to set your preferred party. Raid leads can see this info when using the roster manager, and the automatic distribution system takes it into account.

== Troubleshooting

**Can't click signup button:**

* Signups may be closed - check status embed
* You may be blacklisted - command will tell you
* Thread may be archived - ask raid leader to unarchive
* Bot may be experiencing issues - wait and try again

**Didn't receive reminder:**

* Check DM privacy settings - bot must be able to DM you
* Reminder sends 90 minutes before - check timing
* Test with `/forked-preferences` to verify DMs work
* Bot restarts can prevent delivery (rare)

**Don't see my signup in the list:**

* Use `/my-signups` to verify it registered
* Check if you're on reserves
* Thread embed may be updating slowly
* Contact raid leader if confirmed missing

**Can't select a role:**

* That role may be full - check available slots
* You may need to select multiple roles
* Modal may have timed out - try again

**Roster wasn't distributed:**

* Raid leader distributes manually - may be delayed
* Check thread for announcements
* DM raid leader if less than 30 minutes to start
